In Angular 21 and later, "HttpClient" is available without any setup, and its default backend is the browser "fetch" API. Earlier, it used "XMLHttpRequest" (XHR).

You can still choose XHR with "withXhr()" -

    provideHttpClient(withXhr())

Note that using XHR with SSR is deprecated, and it is planned for removal in Angular 23. Prefer the default (fetch) there.

# PROGRESS EVENTS

Progress reporting is switched off by default. To get progress, use these options, together with "observe: 'events'" -

 - "reportDownloadProgress"
 - "reportUploadProgress"

They replace the older "reportProgress" option, which is deprecated.

Example - download progress -

    this.http.get('/api/big-file', {
        reportDownloadProgress: true,
        observe: 'events',
    }).subscribe((event) => {
        if (event.type === HttpEventType.DownloadProgress) {
            console.log(event.loaded, event.total);
        }
    });

# THE UPLOAD PROGRESS CATCH

The fetch API cannot report upload progress, so the default backend throws an error if you set "reportUploadProgress". If you need upload progress, switch to XHR -

    provideHttpClient(withXhr())

You can read more on the official Angular website - https://angular.dev/guide/http/making-requests
