With the Angular 17, we got a new Control Flow syntax that is much cleaner and similar to the control flow syntax in plain javascript/typescript.

This eliminates the need to use the structural directives such as *ngIf, *ngFor and *ngSwitch. 

The *ngIf, *ngFor and *ngSwitch used a directive-based control flow, but now, we have a built-in control flow for templates.

The new control flow was introduced in Angular 17 as a developer preview and became stable in Angular 18. Since Angular 20, the *ngIf, *ngFor and *ngSwitch directives are officially deprecated, so the built-in control flow (@if, @for and @switch) is the way to write new templates.

If you have an old project that still uses the directives, Angular has a migration that converts them for you automatically -

    ng generate @angular/core:control-flow

(It is also offered when you run "ng update" to Angular 20.)

The new blocks are built into the template compiler, so they are available everywhere without importing anything (no CommonModule, NgIf, NgFor or NgSwitch needed in the "imports" array).
