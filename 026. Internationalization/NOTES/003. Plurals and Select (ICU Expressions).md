Languages have different rules for plurals. "1 minute" and "2 minutes" are different in English, and other languages can have even more forms. Writing this with "@if" would break for translators. Angular uses the ICU message format for this.

# PLURAL

    <span i18n>
        Updated
        {minutes, plural,
            =0 {just now}
            =1 {one minute ago}
            other {{{ minutes }} minutes ago}}
    </span>

 - "minutes" is the value to check.
 - "=0" and "=1" match exact numbers.
 - The category names are "zero", "one", "two", "few", "many" and "other". Which ones a language uses depends on the language.
 - "other" is the fallback, and it should always be there.

# SELECT

"select" chooses text based on a string value -

    <span i18n>
        The author is
        {gender, select, male {male} female {female} other {other}}
    </span>

# THINGS TO KNOW

 - You can nest these expressions.
 - When you extract text, each plural or select expression becomes a separate unit in the translation file. The "ICU" placeholder inside the parent text must not be removed.

You can read more on the official Angular website - https://angular.dev/guide/i18n/prepare
