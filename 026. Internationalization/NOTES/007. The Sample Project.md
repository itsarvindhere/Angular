This section comes with a small project, "i18n-final", that puts every idea from the previous notes on one page. It is built in English, French and Spanish.

Open the folder "i18n-final" and read its README. It has a table that points from each note to the exact place in the code.

# WHAT YOU CAN TRY

 - Run it in one language with "npm run start", "npm run start:fr" or "npm run start:es". The dev server can serve only one locale at a time, which is what we learned in the build note.
 - Run "npm run build" and look at "dist/i18n-final/browser". There is one folder for each language - "en-US", "fr" and "es" - each with its own "lang" attribute and "base href".
 - Click the plus button in the plural example and watch "just now", "one minute ago" and "2 minutes ago" change. Then try the same page in French and Spanish.
 - Change the gender buttons to see the "select" example.
 - Edit a sentence in "app.html", run "npm run extract-i18n" and compare the new "messages.xlf" with the old one.
 - Remove one "target" from "messages.fr.xlf" and build. The build fails, because the project sets "i18nMissingTranslation" to "error".

# TWO THINGS THAT THE SAMPLE SHOWS IN PRACTICE

 1. Custom ids ("@@bookVerb") keep their id when the English text changes, and generated ids do not.
 2. The last line on the page formats a number in German while the page is French or Spanish. For a locale that is not one of the app's own languages, its data has to be registered first with "registerLocaleData" - see "app.ts".
