After marking the text, we need a file that lists all of it, so a translator can work on it.

# EXTRACTING

    ng extract-i18n

This creates "messages.xlf" in the project root. Useful options -

 - "--output-path" - where to write the file.
 - "--out-file" - the file name.
 - "--format" - the file format.

The supported formats are -

 - "xlf" - XLIFF 1.2 (the default)
 - "xlf2" - XLIFF 2
 - "xmb" - XMB, with translations in ".xtb" files
 - "json"
 - "arb"

# TRANSLATING

Make a copy of the file for each language and rename it, for example "messages.fr.xlf". A common place for these is "src/locale". The translator fills in the translated text.

Two rules -

 - Do not change the "trans-unit" IDs, because Angular uses them to match the text.
 - Do not remove the ICU placeholder from plural and select expressions.

# TELLING ANGULAR ABOUT THE LANGUAGES

In "angular.json", under the project -

    "i18n": {
        "sourceLocale": "en-US",
        "locales": {
            "fr": { "translation": "src/locale/messages.fr.xlf" }
        }
    }

"sourceLocale" is the language your templates are written in.

If a translation is missing, you can choose what happens with the build option "i18nMissingTranslation" - it can be "error", "warning" or "ignore".

You can read more on the official Angular website - https://angular.dev/guide/i18n/translation-files
