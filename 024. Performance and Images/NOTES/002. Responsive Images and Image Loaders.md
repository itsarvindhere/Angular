A phone does not need a 3840px wide photo. The browser can pick the right size if we give it a "srcset", and NgOptimizedImage can create one for us.

# srcset AND sizes

 - A fixed-size image gets an automatic "srcset" from its width and height.
 - A responsive image needs "sizes" so the browser knows how wide it will be shown -

        <img ngSrc="cat.jpg" width="800" height="400"
             sizes="(max-width: 768px) 100vw, 50vw" />

 - For lazy images, Angular adds "auto" at the start of "sizes".
 - The default width steps are 16, 32, 48, 64, 96, 128, 256, 384, 640, 750, 828, 1080, 1200, 1920, 2048 and 3840. You can change them with the "IMAGE_CONFIG" token ("breakpoints").
 - To write the list yourself - "ngSrcset="100w, 200w, 300w"". To turn it off for one image, use "disableOptimizedSrcset".

# IMAGE LOADERS

Making several sizes of one image needs a service that can resize on the fly. A "loader" tells Angular how to build the URL for that service. The default loader does no transformation.

Built-in providers -

 - "provideCloudflareLoader"
 - "provideCloudinaryLoader"
 - "provideImageKitLoader"
 - "provideImgixLoader"
 - "provideNetlifyLoader"

    providers: [provideImgixLoader('https://my.base.url/')]

Then use "ngSrc" without the base URL -

    <img ngSrc="cat.jpg" width="400" height="200" />

Pass the domain as a plain string in the provider call, so Angular can generate a preconnect hint for it.

# A CUSTOM LOADER

    providers: [{
        provide: IMAGE_LOADER,
        useValue: (config: ImageLoaderConfig) =>
            `https://cdn.example.com/${config.src}?w=${config.width}`,
    }]

A custom loader must use "config.width", otherwise "ngSrcset" cannot work.

# BLUR-UP PLACEHOLDER

    <img ngSrc="cat.jpg" width="400" height="200" placeholder />

This shows a small blurry version first. It needs an image loader, or it throws an error. If you give a data URL as the placeholder, no loader is needed, but keep it under about 4KB.

You can read more on the official Angular website - https://angular.dev/guide/image-optimization
