The Angular CDK (Component Dev Kit) is a package of behaviour-only building blocks. It contains an accessibility ("a11y") part with two tools that the Angular docs mention.

Install it with -

    npm install @angular/cdk

# LiveAnnouncer

Screen readers read out changes inside "ARIA live regions". "LiveAnnouncer" lets you announce a message from code, without building a live region yourself.

    private announcer = inject(LiveAnnouncer);

    onSaved() {
        this.announcer.announce('Recipe saved');
    }

Use it for things that happen without any visible focus change, like "Item added to cart" or "3 results found".

# cdkTrapFocus

When a modal dialog is open, the keyboard user should not be able to Tab out to the page behind it. The "cdkTrapFocus" directive keeps Tab focus inside an element -

    <div role="dialog" cdkTrapFocus>
        <h2>Delete this recipe?</h2>
        <button>Cancel</button>
        <button>Delete</button>
    </div>

This would be useful for the alert modal we built in the Dynamic Components section.

You can read more on the official Angular website - https://angular.dev/best-practices/a11y
