Building accessible widgets like tabs, menus and listboxes is hard. The keyboard rules, the ARIA attributes and the focus handling all have to be exactly right.

"@angular/aria" is a collection of headless directives for common WAI-ARIA patterns. "Headless" means the directives handle keyboard interaction, ARIA attributes, focus management and screen-reader support, and you provide the HTML, the CSS and the logic. That is useful when you want your own design but do not want to get accessibility wrong.

    npm install @angular/aria

Each pattern is imported from its own path -

    import { Toolbar, ToolbarWidget, ToolbarWidgetGroup } from '@angular/aria/toolbar';

The patterns listed in the docs -

 - Search and selection: Autocomplete, Listbox, Select, Multiselect, Combobox
 - Navigation: Menu, Menubar, Toolbar
 - Content: Accordion, Tabs, Tree, Grid

Status note: the overview page does not state whether the package is stable, so check the Angular roadmap before using it in a production project.

You can read more on the official Angular website - https://angular.dev/guide/aria/overview
