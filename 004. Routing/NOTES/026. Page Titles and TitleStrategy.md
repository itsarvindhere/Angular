The text in the browser tab matters for users and for accessibility - a screen reader announces it when the page changes. The router can set it for us.

# A TITLE ON THE ROUTE

    const routes: Routes = [
        { path: 'about', component: AboutComponent, title: 'About us' },
    ];

The title can also be computed, with a function that returns a string -

    {
        path: 'recipes/:id',
        component: RecipeDetailComponent,
        title: () => inject(RecipeService).currentTitle(),
    }

(Under the hood this is a "ResolveFn<string>", the same kind of function as the resolvers we saw earlier.)

# A TITLE STRATEGY

If you want every page to follow the same pattern, like "Recipe Book - About us", replace the default strategy by extending "TitleStrategy" -

    @Injectable({ providedIn: 'root' })
    export class AppTitleStrategy extends TitleStrategy {
        private title = inject(Title);

        override updateTitle(snapshot: RouterStateSnapshot) {
            const pageTitle = this.buildTitle(snapshot);
            this.title.setTitle(pageTitle ? `Recipe Book - ${pageTitle}` : 'Recipe Book');
        }
    }

Register it -

    providers: [{ provide: TitleStrategy, useClass: AppTitleStrategy }]

"buildTitle" works out the right title from the route that is currently active.

You can read more on the official Angular website - https://angular.dev/guide/routing/define-routes
