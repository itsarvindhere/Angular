So far we created dynamic components programmatically, with "ViewContainerRef". Angular also has two directives that cover the common cases right in the template, with no code. Both come from "@angular/common".

# NgComponentOutlet

Renders a component class that you choose at runtime.

    import { NgComponentOutlet } from '@angular/common';

    @Component({
        imports: [NgComponentOutlet],
        template: `
            <ng-container *ngComponentOutlet="current; inputs: currentInputs" />
        `,
    })
    export class HostComponent {
        current = CompleteComponent;
        currentInputs = { label: 'Complete' };
    }

Useful inputs -

 - "ngComponentOutlet" - the component class;
 - "ngComponentOutletInputs" - an object whose keys are the component's inputs;
 - "ngComponentOutletInjector" / "ngComponentOutletEnvironmentInjector" - custom injectors;
 - "ngComponentOutletContent" - content to project into the component.

The directive also exposes "componentInstance" (read-only).

# NgTemplateOutlet

Renders an "ng-template" at a given place, optionally with a context. This is great for reusing a chunk of markup.

    <ng-template #greeting let-name>
        <span>Hello {{ name }}!</span>
    </ng-template>

    <ng-container *ngTemplateOutlet="greeting; context: { $implicit: 'World' }" />

 - "ngTemplateOutlet" - the template reference;
 - "ngTemplateOutletContext" - an object; each key becomes a "let-" variable, and "$implicit" is the default value;
 - "ngTemplateOutletInjector" - an optional injector.

When do we use which? Use "NgComponentOutlet" when the thing that changes is the component. Use "NgTemplateOutlet" when the same markup is reused or passed around.

https://angular.dev/api/common/NgComponentOutlet
