As part of Angular 20, Angular Animations package was officially deprecated and instead, Angular simplified working with animations using -

    animate.enter
    animate.leave

Angular team suggests replacing your animations that were previously based on @angular/animations with plain CSS or JS-based libraries.

The way we used to work with @angular/animations was quite complicated so the Angular team has reworked on the entire animations functionality in the framework.

Angular team has plans to completely remove the animations property from the Component decorator in Angular 23.

# animate.enter and animate.leave

We can use the 'animate.enter' and 'animate.leave' features to animate elements when they 'Enter' and 'Exit' the DOM. 

For example, let's say we have a list of items where items are added as we keep adding them using an input box. As we add items, we want to animate them as they are added to the list.

Similarly, each list item has a delete button that we can use to remove that item from the list and we want to animate that as well.

This is how simple it is now with 'animate.enter' and 'animate.leave' -

    <ul>
        @for (item of items; track item; let i = $index) {
            <li animate.enter="list-item-enter" animate.leave="list-item-leave">
                {{item}}
                <button (click)="deleteItem(i)">Delete Item</button>
            </li>
        }
        </ul>

Note that here, we pass the name of the classes to the 'animate.enter' and 'animate.leave'.

Now, we can use CSS for these classes -

    .list-item-enter {
        animation: listItemEnter 4s ease-in;
    }

    .list-item-leave {
        animation:
            changeColor 0.5s ease-in forwards,
            slideOut 1s ease-out forwards;
    }

And that's how we can style elements entering and exiting the DOM in Angular.

For other animations, native CSS is enough. For example, if on click of a button, we want to show something but it should appear with a fade animation -

    <button (click)="fadeInOut()"> Fade in / out</button>

    <div
        class="fade-element"
        [class.close]="!isShown"
    >
        This is a block with fade in / out
    </div>

In the class, we have a method that simply toggles a flag -

    fadeInOut() {
        this.isShown = !this.isShown;
    }

And now, we have the 'fade-element' and 'close' classes that we can use for the animations -

    .fade-element {
        opacity: 1;
        transition: opacity 1s ease-in;
    }

    .fade-element.close {
        opacity: 0;
        transition: opacity 1s ease-out;
    }

So, this is now animations now work in latest Angular versions. This is way simpler than what we used to do with the legacy animations package which is now deprecated.
